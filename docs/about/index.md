# 鉄研Wikiとは?

鉄研Wikiは朋優学院高等学校鉄道研究部の今までの活動を**鉄道鬼ごっこ、体育祭と文化祭、運転シュミレーター、プラレール、鉄道ジオラマ**の各ジャンルに分けて記録しておくものです。過去の活動から例えばオープンスクールのプラレールのレイアウトを確認したり、文化祭での業務フローを確認したりするタイミングでお役立てください。

## 使える場面

- **活動記録・アーカイブ**

    鉄道鬼ごっこ、体育祭と文化祭、運転シミュレーター、プラレール、鉄道ジオラマなど、多岐にわたる部活動の記録をジャンルごとに整理して蓄積します。過去の活動内容や成果物をいつでも正確に振り返ることができます。

- **ノウハウ・業務フローの継承**

    オープンスクールでのプラレール大規模レイアウトの組み方や、文化祭における運営の動き、トラブルシューティングなどの実践的なノウハウをドキュメント化します。代が変わっても過去の知見を引き継ぎ、スムーズな準備と運営を実現します。

- **部内共有・資料共有**

    活動に必要な資料や記録をWebサイトとして一元化します。Markdown記法で記述できるため、部員全員が手軽に情報をアップデートでき、いつでも最新の情報を参照できるナレッジベースとして機能します。

## 鉄研Wikiのメリット

- **無料**

    Github Pagesを利用してホスティングしているので、メンテナンスフリーかつ無料でコンテンツを載せることができます。また、朋優学院高等学校鉄道研究部の組織Githubアカウントを利用しているので、メンテナンスする人が卒業あるいは変わったとしても容易に公開を続けることができます。

- **誰でも書ける**

    Markdown記法をベースにしているのでプログラミングの特別な知識がなくても内容を追加、削除、編集できます。また、**Pages CMS**との連携を利用すれば、スマホ、タブレットもちろんPCでもブラウザ経由で直感的なUIを利用して内容を編集できます。

- **デザインは悪くないかな**

    比較的自由に書いてもデザインを自動で整えてくれるので、見やすいドキュメントサイトとして維持できます。
