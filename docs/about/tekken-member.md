# メンバー構成

2026年現在の鉄道研究部の学年別メンバー構成です。

| 学年      | 人数     |
| :-------- | :------- |
| **3年生** | 9名      |
| **2年生** | 9名      |
| **1年生** | 2名      |
| **合計**  | **20名** |

## メンバーに関して

鉄道研究部では現在学年ごとに役割分担は行なっていません。新規で入ってくるメンバーが少ないと、予算の減額や廃部の危機にさらされるので注意が必要です。なんとか、新入部員を確保して、継続して鉄道研究部としての活動を行っていきたいところです。
